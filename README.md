Vice Trophy Guide is an offline GTA VI trophy guide and tracker covering all 55 PlayStation 5 trophies; each trophy listed with official name, description and grade plus an own-words guide citing its sources (Exophase, PSNProfiles and the PlayStation official trophy list); a five-stage platinum roadmap orders the run — story and missables first, then collectibles, activities and the money cleanup — and missable trophies are flagged from wording in the official descriptions; a spoiler shield masks unearned story trophies until earned; progress saved locally in the browser, exportable to a JSON backup and importable on another device; static files only — no build step, no account, no network calls beyond loading its own data file.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. Tick trophies off as you earn them, filter by kind (story, missable, collectibles, activities, online) or grade, and click any trophy to read its guide, steps and sources.
